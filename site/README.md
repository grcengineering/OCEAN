# OCEAN Landing Page

The OCEAN landing page lives at `docs/index.html` and deploys via GitHub Pages to:
**https://grcengineering.github.io/OCEAN/**

## Enabling GitHub Pages (one-time)

Go to: https://github.com/grcengineering/OCEAN/settings/pages
- Source: **Deploy from a branch**
- Branch: `main`
- Folder: `/docs`
- Click **Save**

The site will be live within ~60 seconds at: https://grcengineering.github.io/OCEAN/

## Updating the site

The landing page is `docs/index.html` — single HTML file, no build step needed.
